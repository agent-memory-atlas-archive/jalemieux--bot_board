Base skills: the ones every bot gets.

A base skill reaches every bot on the board, whatever its profile, and a bot with no profile too. It rides on the mechanism that exists: the composed AGENTS.md lists it, the launcher writes it to disk. This sheet is about where a human sees and sets it. Issue #347.

Static studies. Example skills and bots; nothing here talks to a board.

A profile's page / what its bots also carryone treatment

A profile lists its own skills and never changes. Base skills are not the profile's, so they are shown apart: the profile stays honest about what it brings, and a reader still sees what a bot of it will have.
